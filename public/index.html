怎么用，以及怎么拿到聊天记录

1. 拿到 QQ 聊天记录

  • 手机 QQ：进入聊天 → 右上角「≡」→ 聊天记录 → 导出/生成 txt → 发给「文件传输助手」，在电脑上下载。
  • 电脑 QQ：打开聊天窗口，往上滚动加载想看的那段，全选（Ctrl+A）→ 复制 → 粘贴到左边的输入框。
  • 导不出来时：手动按「昵称: 月-日 时:分:秒 + 换行 + 内容」的格式整理几条关键的，10 条以上就够分析了。
  • 支持的格式：「昵称: 10-08 19:01:50」「2024-10-08 19:01:50 昵称」「[2024-10-08 19:01:50] 昵称」「昵称 2024/10/8 19:01」；只有「月-日」时会自动推断年份。

2. 配好模型接口

  • 在左侧「3 模型接口」里填好一条配置，点 连接测试 确认能通（会显示耗时和模型返回的样例）。
  • DeepSeek：地址 https://api.deepseek.com/v1，模型 deepseek-chat，便宜、中文语感好。
  • OpenAI 兼容中转站：把中转站给的地址（一般以 /v1 结尾）和 Key 填进去，模型名照抄文档。
  • Claude：服务商选 Anthropic，地址 https://api.anthropic.com，填 sk-ant- 开头的 Key。
  • 本地模型：装了 Ollama 就选 Ollama，先 ollama pull qwen2.5:14b；完全离线，隐私最好，但分析深度弱一些。
  • 配置会存进本机 config.json，可以存多条随时切换；想彻底抹掉 Key，删掉那条配置或直接编辑该文件。

3. 读报告的建议

  • 先看「本地统计」，那是硬数据：谁更主动、谁的回复更慢、谁在收尾，比任何猜测都可靠。
  • 「逐条解读」是概率判断，把握度低于 60% 的当参考，别当结论。
  • 「我的复盘」里每条都给了改写句，那才是这个小工具最能帮到你的地方——把话说清楚，比猜对方想什么更有用。

4. 常见问题

  • 连接测试报 401：Key 错了；404：地址或模型名不对；429：限流或额度用完。
  • 解析出的说话人不对：把昵称分别填进「我是谁 / 对方是谁」。
  • 记录太长：会自动分段（默认每 400 条一段）再汇总；也可以把「每段消息条数」调到 150-200。
  • 要换端口：node tools/launch.js --port 6000。
